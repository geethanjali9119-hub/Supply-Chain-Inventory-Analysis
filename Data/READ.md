# Dataset

This project uses the DataCo Supply Chain dataset for supply chain, sales, and inventory analysis.

The dataset was cleaned and prepared in Excel before being used for SQL analysis and Power BI dashboard development.

The cleaned dataset is not included in this repository because of its large file size.

## Dataset Files

- DataCoSupplyChainDataset.csv – Main dataset used for the analysis.
- Supply_Chain_Cleaned.csv – Cleaned version of the main dataset used for SQL and Power BI.

## Tools Used

- Excel – Data cleaning and preparation
- SQL – Data analysis
- Power BI – Dashboard and visualization
